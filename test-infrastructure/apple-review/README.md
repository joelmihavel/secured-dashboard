## App Information

## Demo Account Login

| Field | Value |
|-------|-------|
| Phone Number | +91 99999 00017 |
| OTP Code | 303030 |

### Login Steps

1. Launch the app
2. Tap "Get Started" on the carousel screen
3. Enter phone number: **+91 99999 00017**
4. Tap "Send OTP"
5. Enter OTP: **303030**
6. You will be logged into a pre-seeded active account

## What to Test

### Home Dashboard
- View rent payment summary card
- View upcoming payment due date
- View cashback balance
- Scroll to see transaction history preview

### Transactions
- Tap "Transactions" in the bottom navigation
- View list of past rent payments
- Tap any transaction to see details (amount, date, status, payment method)

### Profile
- Tap "Profile" in the bottom navigation
- View profile information (name, phone, email)
- View linked payment methods
- View notification preferences
- View "About" and "Help" sections

### Delete Account
- Navigate to Profile tab
- Scroll to the bottom of the profile screen
- Tap "Delete Account"
- Confirm deletion when prompted

## Important Notes

- **Demo Mode**: This account uses sandbox payment processing. No real money is transferred.
- **Test Phone**: The phone number +91 99999 00017 is a demo number. OTP verification is bypassed with the fixed code 303030.
- **Data**: The account is pre-seeded with sample rent payment history and a configured tenancy for demonstration purposes.
- **Network**: The app requires an active internet connection to communicate with our backend services.

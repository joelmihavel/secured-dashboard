## Codebase Patterns (seed from buildbot-learnings.md)

### Font Mapping
400 → PlusJakartaSans-Regular
500 → PlusJakartaSans-Medium
600 → PlusJakartaSans-SemiBold
700 → PlusJakartaSans-Bold
NEVER use RN fontWeight prop with custom fonts.

### Line Heights
Use Figma lineHeightPx directly as RN lineHeight. No calculation needed.

### DottedPattern Threshold
Screens with DottedPattern have inherent 8-12% pixel diff.
Use 18% odiff threshold for these screens.
Detection: `backgroundShapeKey` in blueprint = DottedPattern screen (Figma names pattern as "image 149" not "dotted pattern").

### Screen Padding
Screen component adds its own padding via `padded` prop.
Don't add horizontal padding to direct children when padded={true}.

### Card Patterns
- Card-with-dividers: Single bg container + thin dividers + gap:8
- Menu-stack: Individual bg containers + gap:4

### ODiff Best Practices
- Always use --reduce-ram-usage flag
- Resize both images to matching dimensions before comparison
- Validate PNG integrity at every I/O boundary
- Cap longest side at 2000px

### Figma Extraction
- depth=999 for full component tree
- designHeight * 4 threshold for shouldSkipNode
- Subtract root bbox.y for relative coordinates
- Check fill.visible and node.visible before rendering
